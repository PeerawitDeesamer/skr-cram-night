# TROUBLESHOOTING — กับดักที่เจ็บมาแล้ว

ทุกข้อในนี้เคยเกิดขึ้นจริงใน workspace นี้ และทุกข้อ **พังแบบเงียบ ๆ** —
หน้าเว็บดูปกติจนถึงตอนที่พึ่งมันไม่ได้ `preflight.py` จึงบล็อกสี่ข้อแรก

## 1. ภาษาไทยกลายเป็น `à¸ªà¸£à¹‰à¸²à¸‡`

เปิดไฟล์แบบ `file://` ไม่มี HTTP header บอก encoding เบราว์เซอร์เลยเดาเป็นรหัสเก่า

**แก้:** `<meta charset="utf-8">` ต้องเป็นบรรทัดแรกใน `<head>` เสมอ

## 2. หน้าโหลดมาไม่มี CSS เลย (Safari เท่านั้น)

Safari บล็อก subresource แบบ `file://` ที่อ้างถึงโฟลเดอร์แม่ (`../assets/...`)
Chrome ยอม — ซึ่งเป็นเหตุผลที่บั๊กนี้รอดจากการเช็ก "ดูปกติดีในเครื่องเรา"

**แก้:** `python3 build.py` ฝัง CSS/JS ลงในทุกหน้า
เขียน `<link href="../assets/lesson.css">` ตามปกติได้ build.py จะแปลงให้เอง

**ของจริง:** บทเรียนเคมีทั้ง 6 หน้าเป็นแบบนี้อยู่จนถึงวันที่ย้ายมาใช้ assets กลาง
เพราะ workspace เคมีไม่เคยมี `build.py`

## 3. ควิซหายไปครึ่งหนึ่ง / มีโค้ดโผล่มาบนหน้า

HTML parser ปิด `<script>` ที่ `</script>` ตัวแรกที่เจอ **แม้อยู่ในคอมเมนต์ JS**
`quiz.js` มีตัวอย่างการใช้งานที่มี `</script>` อยู่ในคอมเมนต์

**แก้:** `build.py` escape เป็น `<\/script>` ให้อัตโนมัติ — อย่าฝัง JS เองด้วยมือ

## 4. ควิซขึ้นแต่กดแล้วไม่มีอะไรเกิดขึ้น

หน้ามี `.quiz` แต่ไม่มี engine อยู่บนหน้า (ลืม `<script>` หรือยังไม่ได้ build)

**แก้:** `build.py` จะฝัง engine ให้แม้ไม่มี `<script>` และแจ้งเตือนตอนทำ ·
`preflight.py` บล็อกถ้ายังไม่มี

## 5. คำอธิบายพูดถึง "ตัวเลือก A" แต่ตัวเลือกถูกสลับ

engine สลับตัวเลือกทุกครั้งที่โหลด แล้วใส่ตัวอักษร A–D ใหม่ตามตำแหน่ง
คำอธิบายที่อ้างตัวอักษรจึงชี้ผิดข้อ

**แก้:** อธิบายด้วย *เนื้อหา* ของตัวเลือก ไม่ใช่ตัวอักษร
หรือใส่ `data-shuffle="off"` เมื่อลำดับมีความหมายจริง ๆ

## 6. `ice()` โยน error ว่ามีรากมากกว่าหนึ่ง

ไม่ใช่บั๊ก ตาราง ICE ที่ให้สองรากที่เป็นไปได้แปลว่าตั้งสมการผิด
หรือลืมตัดของแข็ง/ของเหลวบริสุทธิ์ออกจาก K

**แก้:** ตรวจสมการที่ดุลแล้ว · ใส่ `solid=("CaCO3",)` · หรือกำหนดช่วงด้วย `lo=`/`hi=`

## รูปไม่ขึ้นบน Safari แต่ขึ้นบน Chrome

`<img src="../fig/x.png">` — Safari ไม่ยอมโหลดไฟล์ที่ `file://` อ้างขึ้นไปหาโฟลเดอร์แม่
เหมือนที่มันไม่ยอมโหลด `../assets/lesson.css` (เหตุผลเดียวกับที่ `build.py` มีอยู่)

**แก้:** ย้ายรูปเข้าไปใน `lessons/fig/` แล้วอ้างเป็น `src="fig/x.png"`
`preflight.py` บล็อกให้ตั้งแต่ก่อนส่ง

## รูปกลายเป็นภาพขาวเปล่า หรือเป็นเส้นรบกวน

ครอปด้วย `--box` ที่กะจากการดูหน้าเปล่า ไม่ใช่จาก `figure.py grid`
เรนเดอร์ใหม่ด้วย `grid` แล้วอ่านตัวเลขจากไม้บรรทัดสีแดง

ถ้ากรอบถูกแล้วแต่ยังเพี้ยน แปลว่า `--trim` เล็มจนไม่เหลืออะไร — กรอบนั้นครอบพื้นที่
ที่แทบเป็นสีขาวล้วน ขยายกรอบก่อน อย่าถอด `--trim`

## ป้ายในรูปอ่านไม่ออกเมื่อย่อลงคอลัมน์

`figure.py check` เตือนรูปที่แคบกว่า 520 px ครอปใหม่ด้วย `--dpi` สูงขึ้น (300–400)
ถ้ายังไม่พอ แปลว่าต้นฉบับบนสไลด์ก็เล็กเท่านั้น — ใส่ `class="fig wide"` ให้กว้างเกิน
คอลัมน์ หรือวาด SVG ใหม่เองซึ่งคมทุกขนาด

## ไฟล์บทเรียนอ้วนขึ้นมาก

`figure.py` สลับ PNG ที่เกิน 1.2 MB เป็น JPEG ให้อยู่แล้ว **ชื่อไฟล์จึงเปลี่ยน** —
ถ้า `src` ยังชี้ `.png` อยู่ รูปจะไม่ขึ้น ใช้ชื่อที่สคริปต์พิมพ์ออกมา ไม่ใช่ชื่อที่สั่งไป
