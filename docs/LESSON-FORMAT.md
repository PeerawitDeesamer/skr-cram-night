`build.py` จะเปลี่ยน `<link>`/`<script>` เป็นบล็อกที่ฝังไว้ให้เอง — เขียนแบบข้างบนได้เลย
**ห้ามแก้ `<style>`/`<script>` ที่ถูกฝังในหน้าโดยตรง** จะโดนเขียนทับ

## บล็อก "คัดลงสมุด" (บังคับทุกบท)

ผู้เรียนลอกลง GoodNotes ด้วยมือแล้วไม่กลับมาเปิด HTML อีก บล็อกนี้คือสิ่งเดียว
ที่จะอยู่กับเขาในห้องสอบ ใส่เฉพาะ:
- สูตรหรือขั้นตอนที่ต้องใช้จริง
- กับดักของบทนี้ พูดเป็นประโยคเดียว
- ตัวเลข/เงื่อนไขที่ลืมแล้วทำไม่ได้

ห้ามใส่: นิยามยาว ๆ · ที่มาของสูตร · อะไรที่ค้นได้ตอนอ่านทวน

## หัวข้อ — สีและป้ายมาให้เอง

```html
<h1>ตาราง ICE</h1>              <!-- แดง + ป้าย "หัวเรื่อง" -->
<h2><span class="n">1</span>หลักการ</h2>   <!-- แดง + ป้าย "หัวเรื่อง" -->
<h3>วิธีกรอกแถว I</h3>          <!-- น้ำเงิน + ป้าย "หัวเรื่องย่อย" -->
<h4>ข้อควรระวัง</h4>            <!-- น้ำเงิน + ป้าย "หัวเรื่องย่อย" -->
<h3 class="nolabel">อ่านต่อ</h3><!-- น้ำเงิน ไม่มีป้าย -->
```

แดง = หัวเรื่อง (`h1`, `h2`) · น้ำเงิน = หัวเรื่องย่อย (`h3` ลงไป) — สีผูกกับ**ระดับ**
ของหัวข้อ ไม่ใช่ความสำคัญ และป้ายขึ้นให้เองจาก `lesson.css` (กฎเหล็ก 12)

- **ห้ามตั้งสีหัวข้อเองในหน้า** ไม่ว่าจะ inline `style` หรือ `<span>` สี —
  `preflight.py` เตือน และหน้าที่ตั้งเองจะไม่ตามเมื่อ `lesson.css` เปลี่ยน
- ใช้ระดับให้ตรงความหมาย — `h3` ที่ถูกใช้เพราะ "อยากได้ตัวเล็กลง" ทำให้
  ผู้อ่านเข้าใจว่ามันเป็นหัวข้อย่อยของ `h2` ก่อนหน้า ทั้งที่ไม่ใช่
- หัวข้อที่ไม่ใช่หัวเรื่องของเนื้อหาจริง (หัวกล่อง เมนู) ใส่ `class="nolabel"`
  หรือใช้ `.copy-head` / `.where-head` / `.lbl` ที่มีอยู่แล้วแทน
- **ห้ามใส่ `<mark>` ในหัวข้อ** หัวข้อเด่นอยู่แล้ว ([HIGHLIGHT.md](HIGHLIGHT.md))

## คลาสที่มีให้ใช้

| คลาส | ใช้เมื่อ |
|---|---|
| `.copy` `.copy-head` | บล็อกคัดลงสมุด |
| `.bigidea` | ไอเดียแกนกลางของบท กล่องเดียวต่อบท |
| `.worked` `.step` | ตัวอย่างที่ทำให้ดูทีละขั้น |
| `.ice` | ตาราง ICE |
| `.formula` `.frac` `.eq` | สูตรและเศษส่วน |
| `.callout` | ข้อควรระวัง / กับดัก |
| `.meta` `.tag` | แถบอ้างอิงหน้าในชีท |
| `.ask` | คำถามให้คิดต่อ ท้ายบท |
| `.score` | แถบคะแนนรวมของหน้า (ใส่หนึ่งอันท้ายหน้าที่มีควิซ) |
| `figure.fig` | รูปทุกชนิด — ดึง/ครอปจากสไลด์ หรือโหลดจากแหล่งที่เชื่อถือได้ |
| `figure.fig.wide` | รูปที่ป้ายเยอะจนต้องกว้างเกินคอลัมน์ |
| `.figrow` | 2–3 รูปที่มีความหมายเมื่ออยู่ข้างกัน (ก่อน/หลัง, ปกติ/ผิดปกติ) |
| `.figsrc` | บรรทัดที่มาใน `figcaption` |
| `.where` `.where-head` | ชีวะ: กระบวนการนี้เกิดที่ไหน (บังคับ — กฎเหล็ก 10) |
| `<mark>` | เน้นใจความของประโยค — คำที่ข้ามแล้วความหมายเปลี่ยน |
| `<mark class="key">` | ต้องจำเข้าห้องสอบ — สูตร เงื่อนไข ชื่อกฎ |
| `<mark class="trap">` | จุดที่ข้อสอบดัก คำที่มักถูกสลับ |
| `<mark class="num">` | ตัวเลข ค่าคงที่ หน่วย ที่ผิดแล้วพังทั้งข้อ |
| `<mark class="def">` | ศัพท์ตอนถูกนิยามครั้งแรก (ครั้งเดียว) |
| `.at` | ชื่อตำแหน่งกลางประโยค |
| `.nolabel` | หัวข้อที่ไม่ต้องการป้าย "หัวเรื่อง/หัวเรื่องย่อย" |

## ควิซสามแบบ

```html
<!-- เลือกตอบ — ตัวเลือกถูกสลับตอนโหลด ห้ามอ้างถึง "ตัวเลือก A" ในคำอธิบาย -->
<div class="quiz" data-answer="B" data-tag="ตาราง ICE">
  <div class="qtext">…</div>
  <div class="opts">
    <button class="opt" data-k="A">…</button>
    <button class="opt" data-k="B">…</button>
  </div>
  <div class="fb" hidden data-ok="ทำไมถูก" data-no="ทำไมผิด — อธิบายวิธีคิด ไม่ใช่บอกเฉลย"></div>
</div>

<!-- เติมคำตอบ — ตัวเลขเทียบด้วย tolerance 2% -->
<div class="quiz" data-type="fib" data-answer="0.44" data-unit="M" data-tag="ICE">…</div>

<!-- แบบฝึกหัดของครู — ใบ้ก่อน เฉลยทีหลัง ไม่นับคะแนน -->
<div class="quiz" data-type="reveal" data-hint="เริ่มจากนับ Δn ก่อน"
     data-tag="Kp-Kc">
  <div class="qtext">แบบฝึกหัด 9.3 ข้อ 11</div>
  <div class="fb" hidden data-ok="… วิธีทำครบทุกขั้น …"></div>
</div>
```

`data-tag` ทำให้ข้อที่ผิดถูกจัดกลุ่มตอนจบหน้า — คะแนนกลายเป็นแผนอ่านหนังสือ
ใส่ทุกข้อ

`data-shuffle="off"` เมื่อตัวเลือกเป็นลำดับจริง ๆ (ขั้นที่ 1–4, ค่าเรียงจากน้อยไปมาก)
ใส่บน **`<div class="quiz">`** เท่านั้น — เอนจินอ่านจากตรงนั้น
ถ้าไปใส่บน `<div class="opts">` มันจะไม่ error แต่ **ไม่มีผลเลย** ตัวเลือกยังถูกสลับอยู่ดี
`preflight.py` เตือนให้

## เน้นสี (กฎเหล็ก 11)

ห้าชนิด ไม่มีชนิดที่หก โควตาและเหตุผลอยู่ใน [HIGHLIGHT.md](HIGHLIGHT.md) ตรงนี้คือมาร์กอัป

```html
<p>เมื่อเพิ่มความดันโดยลดปริมาตร ระบบจะปรับไปทาง
   <mark>ที่มีจำนวนโมลแก๊สน้อยกว่า</mark> แต่ถ้าสองฝั่งเท่ากัน
   <mark class="trap">ความดันไม่มีผลต่อตำแหน่งสมดุล</mark>
   โดยใช้ <mark class="num">R = 0.0821 L·atm/mol·K</mark> เสมอ</p>
```

- **ไม่เกิน ~10% ของข้อความในหน้า · ย่อหน้าละ 1–2 จุด · จุดละไม่เกินหนึ่งวรรค**
  เน้นทั้งประโยคคือไม่ได้เน้น `preflight.py` เตือนทั้งสามข้อ
- **ห้ามเน้นใน `<div class="opts">`** ไฮไลต์ในตัวเลือกคือการชี้เฉลย —
  `preflight.py` **บล็อก**
- ใน `data-ok` / `data-no` / `data-hint` ใช้ได้ แต่ต้องใช้ `'` ครอบคลาส:
  `data-ok="… <mark class='trap'>กลับด้าน</mark> …"`
- ใน `.copy` ไฮไลต์แปลว่า "ตรงนี้ลอกผิดบ่อย" ไม่ใช่ "บรรทัดนี้สำคัญ" — 2–3 จุดพอ
- ห้ามใส่ใน `<h1>/<h2>/<h3>` และห้ามใช้แทน `.callout.trap` ที่ต้องอธิบายยาวกว่าหนึ่งวรรค

## รูป (วิชาวิทย์บังคับ — กฎเหล็ก 9)

รายละเอียดการหารูปและโควตาต่อบทอยู่ใน [FIGURES.md](FIGURES.md) ตรงนี้คือมาร์กอัป

```html
<figure class="fig">
  <img src="fig/gut-anatomy.png" alt="ทางเดินอาหารคน มีป้ายชื่ออวัยวะและต่อม">
  <figcaption><b>ตับอ่อนหลั่งเอนไซม์เข้าลำไส้เล็ก ไม่ใช่เข้ากระเพาะ</b> —
    ข้อสอบชอบสลับตรงนี้
    <span class="figsrc">สไลด์ Digestion หน้า 4</span></figcaption>
</figure>
```

- ไฟล์รูปอยู่ที่ `lessons/fig/` เสมอ — `src="fig/…"` **ห้าม `../`** (Safari ไม่โหลด
  แล้วรูปแตกเฉพาะบนเครื่องที่ใช้อ่านจริง) `preflight.py` บล็อกให้
- `alt` บรรยายว่าเห็นอะไร · `figcaption` พูดสิ่งที่ข้อสอบจะถาม · `.figsrc` อ้างที่มา
- ดึงรูปด้วย `scripts/figure.py` — มันพิมพ์บรรทัด `<img …>` ที่ถูกต้องออกมาให้

### ห้ามวาด `<svg>` เอง

`preflight.py` บล็อกหน้าที่มี `<svg>` เขียนด้วยมือ รูปต้องมาจากสไลด์ของครู
(`figure.py pull/crop`) หรือโหลดจากแหล่งที่เชื่อถือได้ (`figure.py fetch`)
เหตุผลและลำดับที่ต้องลองอยู่ใน [FIGURES.md](FIGURES.md)

ข้อยกเว้นเดียวคือกราฟความเข้มข้น–เวลาของ `graph.js` ซึ่งพล็อตจากตัวเลขของชีทเอง
ไม่ได้วาดด้วยตา:

```html
<figure class="cgraph"
        data-series='[{"label":"A","from":1.0,"to":0.40},
                      {"label":"B","from":0,"to":0.60}]'
        data-teq="0.55" data-ymax="1.2"
        data-ylab="ความเข้มข้น (M)" data-xlab="เวลา">
  <figcaption>ที่สมดุล ความเข้มข้นคงที่ <b>ไม่ใช่เท่ากัน</b>
    <span class="figsrc">ตัวเลขจากชีทหน้า 12</span></figcaption>
</figure>
```

### ชีวะ: บล็อก "เกิดที่ไหน" (บังคับ — กฎเหล็ก 10)

วางใต้ `<h2>` ของกระบวนการนั้นทันที **ก่อน** คำอธิบาย รายละเอียดใน [WHERE.md](WHERE.md)

```html
<div class="where"><span class="where-head">เกิดที่ไหน</span>
  <dl>
    <dt>อวัยวะ</dt>       <dd>กระเพาะอาหาร (stomach)</dd>
    <dt>ส่วน / เซลล์</dt> <dd>gastric gland → <b>chief cell</b>, <b>parietal cell</b></dd>
    <dt>สร้างที่</dt>      <dd>chief cell สร้าง pepsinogen (ยังไม่ทำงาน)</dd>
    <dt>ออกฤทธิ์ที่</dt>   <dd><em>ลูเมนของกระเพาะ ไม่ใช่ในเซลล์</em></dd>
  </dl>
</div>
```

`สร้างที่` ≠ `ออกฤทธิ์ที่` เมื่อไร นั่นคือข้อสอบทั้งข้อ · ถ้าเป็นที่เดียวกัน
ยุบเหลือ `<dt>เกิดที่</dt>` แถวเดียว อย่าเขียนซ้ำเพื่อให้ครบฟอร์ม ·
`<em>` ใน `<dd>` = จุดที่ข้อสอบดัก ช่องละไม่เกินหนึ่งที่

กลางประโยคใช้ `<span class="at">ลำไส้เล็ก</span>` ให้คำเรียกตรงกับใน `.where`

### รูปในควิซ

วาง `<figure class="fig">` ระหว่าง `.qtext` กับ `.opts` — โจทย์ "ลูกศร X ชี้อวัยวะใด"
คือข้อสอบชีวะที่เจอบ่อยที่สุด และเป็นแบบที่ฝึกจากตัวหนังสือล้วนไม่ได้
