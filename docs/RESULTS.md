# RESULTS — บรรทัดเดียวหลังได้กระดาษคืน

ระบบนี้ขอจากผู้ใช้อย่างเดียวเท่านั้น: **หัวข้อที่ผิด ตอนที่กระดาษตรวจแล้วกลับมา**
คะแนนบอกว่าอ่อน หัวข้อบอกว่าอ่อนตรงไหน — อย่างหลังเท่านั้นที่ใช้วางแผนต่อได้

```bash
python3 ~/.claude/skills/skr/scripts/results.py add --subject chem \
    --chapter "บทที่ 9 สมดุล" --wrong "ICE table, Kp/Kc" \
    --score 14/20 --note "ทำไม่ทัน 3 ข้อ"
```

`--wrong` คั่นด้วยจุลภาค ใช้ชื่อหัวข้อแบบเดียวกับ `data-tag` ในควิซ
จะได้นับรวมกันได้ · `--score` และ `--note` ไม่ใส่ก็ได้

## เขียนอะไรลงที่ไหน

| ไฟล์ | ใครอ่าน |
|---|---|
| `learning-records/NNNN-result-<chapter>-<date>.md` | คน — บันทึกว่ารู้อะไรจริง |
| `results.jsonl` | เครื่อง — ใช้ถ่วงน้ำหนักบทเรียนชุดหน้า |

`learning-records/` มีอยู่แล้วในทั้งสอง workspace ตามแบบของสกิล `teach`
ตอนนี้ทั้งคู่เขียนไว้ว่า *"ยังไม่มีหลักฐานว่าเข้าใจ"* — ประโยคนั้นคือสิ่งที่คำสั่งนี้มีไว้ลบ

## การถ่วงน้ำหนักอัตโนมัติ

```bash
python3 ~/.claude/skills/skr/scripts/results.py weak --subject chem   # วิชาเดียว
python3 ~/.claude/skills/skr/scripts/results.py weak                  # ทุกวิชา
```

กฎเหล็กข้อ 7 บังคับให้รันคำสั่งนี้ **ก่อนวางแผนทุกครั้ง** ผู้ใช้ไม่ต้องสั่ง
หัวข้อที่ผิดซ้ำมากกว่าหนึ่งครั้งจะถูกดันขึ้นก่อนในลำดับ high-yield
และตอน `add` ถ้าหัวข้อไหนเคยผิดมาแล้ว จะขึ้นเตือนว่า "ผิดซ้ำ" ทันที
