# HIGHLIGHT — เน้นสีที่ข้อความสำคัญ

ตอนตี 1 คนอ่านไม่ได้อ่าน เขา *กวาดตา* หน้าเว็บที่ตัวอักษรเสมอกันหมดทั้งหน้า
ทำให้ไม่มีอะไรให้ตาเกาะ และหน้าที่เน้นทุกบรรทัดก็ให้ผลเท่ากันเป๊ะ — **ถ้าทุกอย่างสำคัญ
แปลว่าไม่มีอะไรสำคัญ** ไฮไลต์จึงเป็นของที่มีต้นทุน ยิ่งใช้มาก ยิ่งจ่ายแพงขึ้นทุกจุด

กฎเดียวที่ต้องจำ: **เน้นเฉพาะคำที่ถ้าอ่านผิดแล้วทำข้อสอบข้อนั้นไม่ได้**
ไม่ใช่คำที่ "ดูสำคัญดี"

## ห้าชนิด แต่ละชนิดตอบคนละคำถาม

| มาร์กอัป | สี | ใช้เมื่อ | อย่าใช้กับ |
|---|---|---|---|
| `<mark>` | เหลือง | ใจความของประโยคนั้น คำที่ถ้าข้ามแล้วประโยคเปลี่ยนความหมาย | ทั้งประโยค |
| `<mark class="key">` | เขียว | สิ่งที่ต้องจำเข้าห้องสอบ — สูตร เงื่อนไข ชื่อกฎ | อะไรที่เปิดดูได้ตอนทำข้อสอบ |
| `<mark class="trap">` | แดง | จุดที่ข้อสอบดัก คำที่มักสลับกัน ("เพิ่ม" vs "ลด", สร้างที่ vs ออกฤทธิ์ที่) | ข้อควรระวังทั่ว ๆ ไป (ใช้ `.callout.trap`) |
| `<mark class="num">` | ฟ้า | ตัวเลข ค่าคงที่ หน่วย ช่วงค่า ที่ผิดแล้วพังทั้งข้อ | ตัวเลขทุกตัวในหน้า |
| `<mark class="def">` | ม่วง | ศัพท์ **ตอนถูกนิยามครั้งแรก** เท่านั้น | ศัพท์เดิมที่โผล่ซ้ำอีกสิบครั้ง |

สีอย่างเดียวเชื่อไม่ได้ ทุกชนิดจึงมีขีดล่างสีของตัวเองด้วย — ตาบอดสีแยกเหลืองกับ
เขียวอ่อนไม่ออก และปรินต์ขาวดำแล้วพื้นหลังกลายเป็นเทาเท่ากันหมด
(`print-color-adjust:exact` ทำให้สีติดตอนปรินต์สี ขีดล่างรับช่วงต่อตอนปรินต์ขาวดำ)

## โควตา

- **ไม่เกิน ~10% ของข้อความในหน้า** `preflight.py` เตือนเมื่อเกิน
- **ย่อหน้าละไม่เกิน 1–2 จุด** ย่อหน้าที่มีสามจุดขึ้นไป แปลว่ายังไม่ได้ตัดสินใจ
  ว่าอะไรสำคัญที่สุด
- **จุดละไม่เกินหนึ่งวรรค** (~60 ตัวอักษร) เน้นทั้งประโยค = ตาไม่รู้จะเกาะตรงไหน
  ถ้าประโยคทั้งประโยคสำคัญจริง มันควรอยู่ใน `.copy` หรือ `.bigidea` ไม่ใช่ถูกทาสี
- **ห้ามซ้อนใน `<h1>/<h2>/<h3>`** หัวข้อเด่นด้วยตัวมันเองอยู่แล้ว

## ที่ที่ห้ามเน้น เพราะมันเฉลยให้

```html
<!-- ผิด: ตาไปหยุดที่ตัวเลือกที่ทาสี ก่อนจะได้คิด -->
<button class="opt" data-k="B">ค่า K <mark class="num">ไม่เปลี่ยน</mark></button>
```

ไฮไลต์ใน `<div class="opts">` คือการชี้เฉลย ผู้อ่านตอบถูกโดยไม่ได้คิด แล้วเข้าใจว่า
ตัวเองรู้เรื่องนี้แล้ว — `preflight.py` **บล็อก** ไม่ใช่เตือน
เน้นในโจทย์ (`.qtext`) ได้ ถ้าเน้นเงื่อนไขของโจทย์ ไม่ใช่คำที่ชี้ไปทางคำตอบ

## เน้นในเฉลยและใบ้

`data-ok` / `data-no` / `data-hint` ถูกใส่ลงหน้าด้วย `innerHTML` — `<mark>` ทำงาน
แต่ค่าของแอตทริบิวต์ครอบด้วย `"` อยู่แล้ว **ข้างในต้องใช้ `'`**

```html
<div class="fb" hidden
     data-ok="ตรงนี้ต้องใช้ K ของสมการที่ <mark class='trap'>กลับด้าน</mark> แล้ว"></div>
```

## ในบล็อก "คัดลงสมุด"

ทั้งบล็อกสำคัญอยู่แล้ว ไฮไลต์ในนั้นจึงไม่ได้แปลว่า "บรรทัดนี้สำคัญ" แต่แปลว่า
**"ตรงนี้คือจุดที่ลอกผิดบ่อย"** — เครื่องหมาย ตัวห้อย/ตัวยก ทิศของลูกศร เลขยกกำลัง
ใช้ได้ไม่เกิน 2–3 จุดต่อบล็อก

```html
<div class="copy"><span class="copy-head">คัดลงสมุด</span>
  <ul>
    <li>K<sub>p</sub> = K<sub>c</sub>(RT)<sup><mark class="trap">Δn</mark></sup>
        — Δn นับจาก <mark class="num">โมลแก๊ส ฝั่งขวา − ฝั่งซ้าย</mark> เท่านั้น</li>
  </ul>
</div>
```

## ก่อน / หลัง

```html
<!-- ก่อน: อ่านสองรอบก็ยังไม่รู้ว่าข้อสอบจะจับตรงไหน -->
<p>เมื่อเพิ่มความดันโดยลดปริมาตร ระบบจะปรับไปทางที่มีจำนวนโมลแก๊สน้อยกว่า
   แต่ถ้าจำนวนโมลแก๊สสองฝั่งเท่ากัน ความดันจะไม่มีผลต่อตำแหน่งสมดุล</p>

<!-- หลัง: สองจุด จุดละไม่กี่คำ ที่เหลือปล่อยเป็นเนื้อความ -->
<p>เมื่อเพิ่มความดันโดยลดปริมาตร ระบบจะปรับไปทาง
   <mark>ที่มีจำนวนโมลแก๊สน้อยกว่า</mark> แต่ถ้าสองฝั่งเท่ากัน
   <mark class="trap">ความดันไม่มีผลต่อตำแหน่งสมดุล</mark></p>
```

## preflight บอกอะไรบ้าง

| อาการ | ผล |
|---|---|
| `<mark>` อยู่ใน `<div class="opts">` | **บล็อก** — ชี้เฉลย |
| `class` ที่ไม่มีอยู่จริง (พิมพ์ผิด เช่น `keys`) | เตือน — ได้สีเหลืองเงียบ ๆ ทั้งที่ตั้งใจเป็นอย่างอื่น |
| ข้อความที่เน้นเกิน ~10% ของหน้า | เตือน — เน้นเยอะจนไม่เหลือความสำคัญ |
| จุดเดียวยาวเกิน 100 ตัวอักษร หรือคร่อมแท็กบล็อก | เตือน — เท่ากับไม่ได้เน้น |
| บทเรียนที่ไม่มีไฮไลต์เลย | เตือน — หน้าที่ตาไม่มีที่เกาะ คือหน้าที่ถูกเลื่อนผ่าน |
| `<mark>` ใน `<h1>/<h2>/<h3>` | เตือน — หัวข้อเด่นอยู่แล้ว |
