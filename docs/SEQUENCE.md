# SEQUENCE — เรียงเนื้อหาก่อนสอน ไม่ใช่สอนตามหน้าสไลด์

สไลด์ของครูถูกทำมาให้ **พูดประกอบ** ไม่ได้ทำมาให้อ่านเอง ครูพูดเชื่อมช่องว่างให้ในห้องเรียน
ไฟล์ที่เหลือมาจึงมีรอยต่อที่ไม่มีใครเชื่อม:

- **เรื่องเดียวกันถูกแบ่งไว้คนละที่** ทางเดินอาหารคนอยู่หน้า 14 แล้วกลับมาอีกทีหน้า 31–32
- **ใช้ศัพท์ก่อนนิยาม** พูดถึง bolus หน้า 15 แต่ไปอธิบายจริงหน้า 37
- **สองเรื่องไม่เกี่ยวกันวางติดกัน** เพราะบังเอิญบรรยายต่อกันในคาบนั้น
- **หน้าที่เป็นวิดีโอ/ลิงก์คั่นกลาง** ซึ่งไม่มีเนื้อหาเลยเมื่ออ่านจากไฟล์

**สอนตามลำดับหน้า = ลอกรอยต่อเหล่านี้เข้ามาในบทเรียนทั้งชุด** แล้วผู้เรียนจะเจอศัพท์
ที่ไม่เคยถูกให้ ตอนตีหนึ่ง ตอนที่ไม่มีครูให้ถาม

## ลำดับงาน

### 1. ทำแผนที่ก่อน (mechanical — ให้สคริปต์ทำ)

```bash
S=~/.claude/skills/skr
python3 $S/scripts/outline.py map     "Slides/Digestion.pdf" --pages 1-44
python3 $S/scripts/outline.py scatter "Slides/Digestion.pdf"
```

`map` บอกว่าแต่ละหน้า **เพิ่มศัพท์อะไรใหม่** (ศัพท์ที่โผล่ไปแล้วไม่นับซ้ำ — สิ่งที่หน้าหนึ่ง
เพิ่มเข้ามาคือสิ่งที่ใช้ตัดสินลำดับ) · `scatter` บอกว่าศัพท์ไหนถูกสอนไว้หลายที่ห่างกัน

ใช้ได้เฉพาะศัพท์อังกฤษ เพราะ text layer ภาษาไทยตกวรรณยุกต์ ([SHEETS.md](SHEETS.md))
สำหรับชีทวิทย์ไทยเท่านี้พอ — ศัพท์ที่ค้ำโครงเรื่อง (essential amino acid, gastrovascular
cavity, gizzard) เป็นอังกฤษหมดอยู่แล้ว

**หน้าที่เป็นสแกน สคริปต์มองไม่เห็น** มันจะบอกว่าหน้าไหนบ้าง — ต้อง `sheet.py render`
แล้วอ่านเองก่อน ไม่งั้นแผนที่จะมีรูโหว่ตรงหน้าที่อาจสำคัญที่สุด

ถ้าเกินครึ่งเล่มเป็นสแกน `scatter` จะ **ไม่ยอมสรุปอะไรเลย** และบอกตรง ๆ ว่ามันมองไม่เห็น
(บนเครื่องนี้ `plant hormone.pdf` และ `Cell Respiration .pdf` เป็นสแกนล้วนทั้งเล่ม)
คำว่า "ลำดับดูโอเค" ที่ออกมาจากหน้าที่ไม่เคยถูกอ่าน คือคำตอบที่อันตรายที่สุดที่มันให้ได้
เพราะตอนตีหนึ่งจะไม่มีใครสงสัย

### 2. ตัดสินลำดับ (ไม่ mechanical — Opus ทำเอง ห้ามมอบต่อ)

`outline.py` **ไม่จัดลำดับให้** และตั้งใจให้เป็นแบบนั้น การตัดสินว่าอะไรต้องเข้าใจก่อนอะไร
คือการตัดสินใจเรื่องการสอน ไม่ใช่การนับคำ

เกณฑ์เรียงตามลำดับความสำคัญ เมื่อขัดกันให้ข้อบนชนะ:

1. **ต้องรู้ก่อนถึงจะอ่านข้อถัดไปรู้เรื่อง** — ศัพท์ต้องถูกนิยามก่อนถูกใช้เสมอ
   ข้อนี้ชนะทุกข้อ บทที่อ่านไม่รู้เรื่องคือบทที่ไม่มีค่าไม่ว่าจะ high-yield แค่ไหน
2. **high-yield ก่อน** (กฎเหล็ก 2) ถ้าเวลาหมดกลางทาง สิ่งที่เสร็จต้องเป็นสิ่งที่สำคัญที่สุด
3. **รวมเรื่องที่ครูแยกไว้ ถ้ามันคือเรื่องเดียวกัน** — `scatter` ชี้ให้แล้ว
4. **แยกเรื่องที่ครูวางติดกัน ถ้ามันคนละเรื่อง** — ติดกันในสไลด์ไม่ได้แปลว่าเกี่ยวกัน

### 3. บอกผู้ใช้ว่าจัดใหม่ยังไง และเพราะอะไร (บังคับ)

**ห้ามจัดลำดับใหม่เงียบ ๆ** ผู้เรียนถือชีทฉบับเดียวกันอยู่ และจะเปิดสลับไปมาระหว่าง
บทเรียนกับชีทตลอดคืน ถ้าลำดับไม่ตรงกันโดยไม่บอก เขาจะคิดว่าตัวเองเปิดผิดหน้า

พูดสั้น ๆ ตอนเสนอโครงบท ก่อนเขียนไฟล์:

> สไลด์เรียงแบบนี้: หน้า 14 ทางเดินอาหารคนแบบผ่าน ๆ → หน้า 15–30 ย่อยทีละอวัยวะ →
> หน้า 31–32 กลับมาทางเดินอาหารอีกรอบ
> ผมจะรวมหน้า 14 กับ 31–32 เป็นบทเดียวไว้ **ก่อน** เพราะบท 15–30 อ้างถึงอวัยวะ
> พวกนี้ตลอดโดยไม่ได้แนะนำ · ส่วนหน้า 18/21/36 เป็นลิงก์วิดีโอ ไม่มีเนื้อหา ข้ามครับ

### 4. เขียนแผนที่ลง NOTES.md (ทำครั้งเดียว ใช้ได้ตลอด)

```bash
python3 $S/scripts/outline.py map "Slides/Digestion.pdf" --md >> NOTES.md
```

คืนหน้าที่สอบเรื่องเดิม จะได้ไม่ต้องไล่ใหม่ทั้งเล่ม
(`Biology/NOTES.md` มีตารางแบบนี้ของ `plant hormone.pdf` อยู่แล้ว — ทำต่อในรูปเดียวกัน)

## ทุกบทต้องยังชี้กลับไปที่ชีทได้

จัดลำดับใหม่ได้ แต่ **ห้ามตัดสายที่โยงกลับไปหาชีท** แถบ `.meta` ของทุกบทต้องบอกหน้าจริง
และถ้าบทหนึ่งรวมหลายช่วงหน้าเข้าด้วยกัน ให้เขียนให้ครบทุกช่วง:

```html
<div class="meta">
  <span class="tag">ชีทหน้า 14</span><span class="tag">+ หน้า 31–32</span>
  <span class="tag">~15 นาที</span>
</div>
```

ผู้เรียนต้องเปิดชีทตามได้เสมอ ([VERIFY.md](VERIFY.md))

## กับดักที่เจอบ่อย

**อย่าจัดใหม่จนกลายเป็นหลักสูตรของตัวเอง** เป้าหมายคือทำให้ชีท*ของครู*อ่านรู้เรื่อง
ไม่ใช่สอนเรื่องเดียวกันด้วยโครงที่ตัวเองชอบกว่า ถ้าลำดับของครูใช้ได้อยู่แล้ว ก็ใช้ตามนั้น
แล้วบอกว่า "ลำดับในสไลด์ใช้ได้ ผมเรียงตามเดิม" — นั่นก็เป็นคำตอบที่ถูก

**หน้าที่ครูข้ามในคาบ ไม่ใช่หน้าที่ไม่ออกสอบ** ถ้าไม่แน่ใจว่าช่วงไหนออก ให้ถามตอนล็อกสเปก
(คำถามข้อ 1) อย่าเดาจากการที่สไลด์ดูไม่สำคัญ

**ลำดับที่จัดแล้วต้องอยู่ในชื่อไฟล์ด้วย** `0001-…` `0002-…` เรียงตามลำดับที่จะให้อ่าน
ไม่ใช่ตามเลขหน้าในชีท และลิงก์ `.nav` ท้ายบทต้องพาไปบทถัดไป**ตามลำดับที่จัดไว้**
