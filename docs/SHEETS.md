# SHEETS — อ่านชีทของครู

## probe ก่อนเสมอ

```bash
python3 ~/.claude/skills/skr/scripts/sheet.py probe "บทที่ 9 สมดุล 2569.pdf"
```

บอกสามอย่าง: กี่หน้า · มี text layer กี่ตัวอักษร · เป็นชีทแบบไหน

| ผล | แปลว่า | ทำต่อ |
|---|---|---|
| `TEXT` | ชีทพิมพ์มา อ่านได้ทันที | `sheet.py text` |
| `SCAN` | ถ่ายเอกสารมา ไม่มีตัวอักษรเลย | `sheet.py render` แล้วดูภาพ |
| `MIXED` | บางหน้าเป็นภาพ (มักเป็นหน้ารูป/กราฟ) | ใช้ทั้งสองอย่าง |

ที่ต้อง probe ก่อนเพราะการเดาผิดเสียเวลาสองรอบ และคืนก่อนสอบไม่มีให้เสีย
ของจริงบนเครื่องนี้: เคมีทั้งสามบท = `TEXT` · `plant hormone.pdf` = `SCAN` ล้วน 18 หน้า

## อ่านแล้วอย่าเพิ่งเขียน — ทำแผนที่ก่อน

`probe` บอกว่าอ่านได้ไหม แต่ไม่ได้บอกว่าเนื้อหา *เรียงมาดีหรือเปล่า* ซึ่งมักจะไม่
ทำแผนที่ด้วย `outline.py` ในรอบเดียวกัน ก่อนตัดสินใจแบ่งบท ([SEQUENCE.md](SEQUENCE.md))

## อ่านเป็นข้อความ

```bash
python3 ~/.claude/skills/skr/scripts/sheet.py text "ชีท.pdf" --pages 20-30
```

พิมพ์แต่ละหน้าคั่นด้วย `=== page N ===` — เลขหน้านี้คือสิ่งที่ต้องเอาไปใส่
ในแถบ `.meta` ของบทเรียน ทุกคำอ้างต้องย้อนกลับไปหาหน้าได้

## เรนเดอร์หน้าสแกน

```bash
python3 ~/.claude/skills/skr/scripts/sheet.py render "ชีท.pdf" --pages 1-6 --out pages --dpi 150
```

ได้ `pages/p001.png …` แล้วอ่านด้วยเครื่องมืออ่านภาพ
150 dpi พอสำหรับตัวหนังสือ ขึ้น 200 เฉพาะตอนที่กราฟอ่านไม่ออก —
ภาพใหญ่ขึ้นแปลว่าช้าลง และคืนนี้ไม่มีเวลาเหลือ

เรนเดอร์ทีละ 6 หน้า อย่าเรนเดอร์ 18 หน้ารวดเดียวแล้วค่อยคิดว่าจะใช้หน้าไหน

## กับดัก: text layer ภาษาไทยตกวรรณยุกต์

ชีทเคมีที่ครูทำจาก Word มี text layer ที่ **ตกสระ/วรรณยุกต์บางตัว** ตอนดึงออกมา
เช่นในชีทบทที่ 8 หน้า 5 ตัวจริงเขียนว่า "พบว่า" แต่ `sheet.py text` ได้ "พบวา"
และ "ตัวอย่างที่" กลายเป็น "ตัวอยางที่"

เกิดจากการ map ฟอนต์ใน PDF ไม่ใช่ความผิดของสคริปต์ และ **ไม่กระทบตัวเลข**

**กฎ:** ห้ามลอกข้อความจาก text layer ลงบทเรียนตรง ๆ ต้องพิมพ์ใหม่ให้ถูกต้อง
ตัวเลข สมการ และตารางเชื่อถือได้ · ถ้อยคำภาษาไทยต้องเขียนใหม่เสมอ
ถ้าต้องคัดข้อความยาวหรือไม่แน่ใจ ให้ `render` หน้านั้นเป็นภาพแล้วอ่านจากภาพแทน

## ตารางที่ดึงออกมาแล้วคอลัมน์ปนกัน

ตารางใน PDF มักออกมาเป็นตัวเลขเรียงยาวโดยไม่มีเส้นแบ่ง เช่น ตย. 8.3
ออกมาเป็น `3 4 0 0 / 1 1 1 3 / 4 4 4 4`

**วิธีตรวจว่าตีความถูก:** ใช้ความสอดคล้องภายในของเคมีเอง — อัตราของแต่ละสาร
หารด้วยเลขสัมประสิทธิ์ต้องได้ค่าเท่ากันทุกตัว ใส่การตรวจนี้ลง `verify.py`
ถ้าไม่เท่ากัน แปลว่าอ่านตารางผิด ไม่ใช่ว่าชีทผิด
