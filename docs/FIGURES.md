# FIGURES — บทเรียนวิทย์ต้องมีรูป ไม่ใช่มีก็ดี

คืนก่อนสอบ ผู้เรียนอ่านหน้าที่มีรูปจนจบ และเลื่อนผ่านหน้าที่เป็นตัวหนังสือล้วน
ไดอะแกรมที่ครูวางไว้บนสไลด์คือรูปที่จะโผล่ในข้อสอบ และเป็นรูปที่คนตรวจคาดว่าจะเห็น
การเขียนบรรยายแทนรูปนั้นทิ้งของฟรีนี้ไปเปล่า ๆ

## โควตา (กฎเหล็ก 9)

| วิชา | ต่อหนึ่งบท |
|---|---|
| ชีววิทยา | **≥ 4 รูป** — โครงสร้าง/อวัยวะ/วงจร ทุกอันที่ชีทวาด ต้องมีในบท |
| เคมี | **≥ 3 รูป** — กราฟ แผนภาพพลังงาน อุปกรณ์ ตารางที่อ่านง่ายกว่าเป็นภาพ |
| ฟิสิกส์ | **≥ 3 รูป** — free-body diagram, กราฟ, ภาพสถานการณ์ของโจทย์ |
| คณิต | **≥ 2 รูป** — กราฟฟังก์ชัน รูปเรขาคณิตของโจทย์ |

นับเฉพาะรูปที่ *สอนอะไรบางอย่าง* — ไอคอน เส้นคั่น โลโก้ ไม่นับ
`preflight.py` นับให้และเตือนถ้าไม่ถึง แต่ไม่บล็อก เพราะ 23:00 แล้วส่งของที่ไม่ครบ
ยังดีกว่าไม่ส่ง — ถ้าไม่ถึงโควตาต้อง **บอกผู้ใช้ตรง ๆ ว่าบทไหนขาด** ตอนส่งมอบ

**รูปเดียวที่ตรงจุดชนะสามรูปที่พอเกี่ยวข้อง** โควตาคือพื้น ไม่ใช่เพดาน
และห้ามใส่รูปที่ไม่มีอะไรจะสอนเพื่อให้ตัวเลขผ่าน

## หารูปจากไหน เรียงตามที่ควรลองก่อน

### 1. รูปฝังในสไลด์/ชีทของครู — ดีที่สุด

```bash
S=~/.claude/skills/skr
python3 $S/scripts/figure.py list "Slides/Digestion.pdf" --pages 4-9
python3 $S/scripts/figure.py pull "Slides/Digestion.pdf" \
        --page 4 --index 0 --out lessons/fig/gut-anatomy.png
```

`list` บอกว่ามีรูปอะไรฝังอยู่หน้าไหน ขนาดเท่าไร และอยู่ตรงไหนของหน้า
`pull` ดึงออกมาที่ความละเอียดต้นฉบับ — ไม่มีพื้นหลังสไลด์ ไม่มีหัวข้อติดมา
ไม่ใช่ภาพถ่ายของภาพถ่าย **ลองอันนี้ก่อนเสมอ**

ถ้าไฟล์ที่ได้อ้วนเกิน `save()` จะสลับเป็น `.jpg` ให้เอง — ชื่อไฟล์ที่พิมพ์ออกมา
คือชื่อจริงที่ต้องเอาไปใส่ใน `src` ไม่ใช่ชื่อที่สั่งไป

### 2. ครอปจากหน้าสไลด์ — เมื่อรูปเป็นเวกเตอร์ หรือครูประกอบจากหลายชิ้น

```bash
python3 $S/scripts/figure.py grid "Slides/plant structure.pdf" --pages 12 --out /tmp/grid
# เปิดดู /tmp/grid/grid-p012.png แล้วอ่านกรอบจากเลขสีแดงขอบภาพ
python3 $S/scripts/figure.py crop "Slides/plant structure.pdf" \
        --page 12 --box 48,28,96,86 --out lessons/fig/xylem.png --trim
```

`grid` วาดไม้บรรทัด 0–100 ทับหน้าไว้ให้ (ไม่แก้ไฟล์ PDF จริง) กรอบจึงเป็นค่าที่
**อ่านได้** ไม่ใช่ค่าที่เดา — เดาผิดหนึ่งครั้งคือเรนเดอร์ใหม่หนึ่งรอบที่ไม่มีเวลาให้เสีย

`--trim` เล็มขอบขาวที่ติดมาจากการกะกรอบด้วยตา ใส่ไว้เกือบทุกครั้ง
ไม่ใส่เมื่อรูปมีพื้นหลังสีอ่อนที่เป็นส่วนหนึ่งของรูป (แผนภาพที่ระบายสีพื้น)

**ครอปให้เหลือแค่รูป** ห้ามครอปติดข้อความไทยของสไลด์มาด้วย — ข้อความอยู่ในบทเรียน
แล้ว ครอปติดมาคือของซ้ำที่กินที่และอ่านไม่ออกเมื่อย่อลงคอลัมน์

### 3. โหลดจากแหล่งที่เชื่อถือได้ — เมื่อชีทไม่มีรูปนั้นจริง ๆ

```bash
python3 $S/scripts/figure.py fetch \
        "https://upload.wikimedia.org/wikipedia/commons/d/da/Cell_membrane_detailed_diagram_en.svg" \
        --out lessons/fig/membrane.png \
        --cite "Wikimedia Commons — LadyofHats, public domain"
```

เงื่อนไข ห้ามข้ามข้อไหน:

- **ห้าม hotlink** ต้องโหลดลง `lessons/fig/` เสมอ หน้าเรียนถูกเปิดออฟไลน์จาก `file://`
  และลิงก์ที่ตายในอีกเดือนคือบทเรียนที่มีรูโหว่ (`fetch` โหลดลงเครื่องให้อยู่แล้ว)
- **ต้องมี `--cite`** ที่มา + สัญญาอนุญาต เขียนลง `fig/SOURCES.md` อัตโนมัติ
  พร้อม URL จริงหลัง redirect และ sha256 ของไฟล์ต้นฉบับ
- **ต้องตรงกับที่ครูสอน** ไดอะแกรมวงจร Krebs ของฝรั่งที่ตั้งชื่อสารคนละแบบกับชีท
  ทำให้จำผิดในห้องสอบ — รูปที่ชื่อไม่ตรงชีท **ไม่เอาดีกว่า** ให้กลับไปหาในสไลด์
  หน้าอื่น หรือหารูปอื่นที่ป้ายตรงกัน
- **ต้องเปิดดูด้วยตาก่อนใส่ในบท** ทุกรูป ไม่มีข้อยกเว้น

**หา URL จริงของ Wikimedia ยังไง** URL รูปย่อ (`…/thumb/…/900px-….png`) เดาเองไม่ได้
ขนาดที่ไม่มีในแคชคืน **400/404** ทั้งที่ไฟล์ต้นฉบับมีอยู่จริง ถามผ่าน API ก่อน:

```bash
curl -sS -A skr "https://commons.wikimedia.org/w/api.php?action=query&format=json\
&titles=File:ชื่อไฟล์.svg&prop=imageinfo&iiprop=url" |
  python3 -c "import sys,json;p=list(json.load(sys.stdin)['query']['pages'].values())[0];\
print(p['imageinfo'][0]['url'])"
```

ได้ URL ต้นฉบับมาแล้วส่งให้ `fetch` ได้เลย — SVG จะถูกแปลงเป็น PNG ให้เอง
ไม่ต้องไปหาลิงก์รูปย่อ

### รูปจากเน็ตต้องปลอดภัย — สคริปต์บังคับให้ ไม่ได้ฝากไว้กับความระวัง

ไฟล์จากคนแปลกหน้าถูกเปิดบนเครื่องที่ใช้เรียน `figure.py fetch` จึงกัน 5 ชั้น
และกันด้วยการ *ทำให้เป็นไปไม่ได้* ไม่ใช่การเตือน:

1. **https เท่านั้น** และ redirect ทุกขั้นต้องเป็น https (`--proto-redir =https`)
2. **โฮสต์ต้องอยู่ในรายชื่อ** Wikimedia/Wikipedia · OpenStax · NIH/NCBI · NASA ·
   NOAA/USGS · CDC/WHO · Europe PMC และทุกโดเมนใต้ `.gov .edu .ac.th .go.th .int`
   ปลายทางหลัง redirect ถูกตรวจอีกรอบ — เด้งออกนอกรายชื่อคือทิ้งไฟล์
   โฮสต์อื่น ต้อง **ถามผู้ใช้ก่อน** แล้วค่อยใส่ `--trust HOST` ห้ามใส่เอง
3. **content-type ต้องเป็นรูป** และ magic byte ต้องตรงกับรูปจริง
   หน้า HTML ที่ปลอมนามสกุลเป็น `.png` ตกตรงนี้
4. **บีบขนาดที่ 20 MB** (`--max-filesize`) ไฟล์ที่ใหญ่กว่านั้นไม่ใช่ไดอะแกรม
5. **เข้ารหัสใหม่ทุกไฟล์ ไบต์ที่โหลดมาไม่ถูกเก็บไว้เลย** pymupdf อ่านแล้วเขียน
   PNG ใหม่ทับ — **SVG ถูกแปลงเป็นภาพแรสเตอร์** ที่จุดนี้ `<script>`
   `foreignObject` และ `<image href="http…">` ที่ซ่อนใน SVG จึงไปต่อไม่ได้
   มันกลายเป็นพิกเซลไปแล้ว (SVG คือ XML ที่รันสคริปต์ได้ ไม่ใช่รูปเฉย ๆ —
   นี่คือเหตุผลที่ไม่มีการเก็บ `.svg` ลง `fig/` จากเน็ต)

ถ้า `fetch` ปฏิเสธ **อย่าหาทางอ้อมด้วย curl เอง** ข้อความที่มันพิมพ์คือเหตุผล
ที่รูปนั้นไม่ควรอยู่ในบทเรียน

### ห้ามวาดรูปขึ้นมาเอง

**ไม่มีการเขียน `<svg>` ด้วยมือในบทเรียน ไม่ว่ากรณีใด** `preflight.py` บล็อก

รูปที่วาดเองคือรูปที่ไม่มีใครตรวจกับชีท มันดูน่าเชื่อถือเท่ารูปจริงทุกประการ
และผิดได้ตรงจุดที่ข้อสอบถามพอดี — ลูกศรกลับทิศ ป้ายอยู่ผิดชั้น ลำดับขั้นขาดไปหนึ่ง
คืนก่อนสอบไม่มีเวลาพิสูจน์ว่ารูปที่วาดเองถูก และรูปที่จำผิดไปแล้วแก้ยากกว่าไม่เคยเห็น

เรื่องที่ชีทไม่มีรูป ให้ทำตามลำดับนี้:

1. หาในสไลด์หน้าอื่น — เรื่องเดียวกันมักถูกวาดไว้อีกที่ (`outline.py scatter` ชี้ให้)
2. `fetch` จากแหล่งในรายชื่อ ที่ป้ายตรงกับชีท
3. ไม่มีจริง ๆ → เขียนเป็น **ตาราง** หรือ `.copy` ที่เป็นขั้นตอนเป็นข้อ ๆ
   แล้ว **บอกผู้ใช้ตรง ๆ ว่าบทนี้ขาดรูปเรื่องอะไร** อย่าเติมรูปปลอมให้ครบโควตา

**ข้อยกเว้นเดียว: กราฟของ `graph.js`** (`<figure class="cgraph" data-series=…>`)
นั่นไม่ใช่การวาด — มันคือการพล็อตตัวเลขที่อยู่ในชีทอยู่แล้ว เส้นทุกเส้นมาจาก
ค่าที่ใส่ใน `data-series` ไม่ได้มาจากการกะด้วยตา

## เขียนลงหน้าบทเรียน

```html
<figure class="fig">
  <img src="fig/gut-anatomy.png" alt="ทางเดินอาหารคน ตั้งแต่ปากถึงทวารหนัก
       มีป้ายชื่ออวัยวะและต่อมที่หลั่งเอนไซม์">
  <figcaption><b>ตับอ่อนหลั่งเอนไซม์เข้าลำไส้เล็ก ไม่ใช่เข้ากระเพาะ</b> —
    ข้อสอบชอบสลับตรงนี้ ดูทิศของท่อในรูปให้ชัด
    <span class="figsrc">สไลด์ Digestion หน้า 4</span></figcaption>
</figure>
```

**สามข้อบังคับ:**

1. **`alt` ต้องบรรยายว่าเห็นอะไร** ไม่ใช่ `alt="รูป"` — รูปที่โหลดไม่ขึ้นตอนตี 1
   ต้องยังบอกได้ว่าเคยมีอะไรอยู่ตรงนั้น
2. **`figcaption` ต้องพูดสิ่งที่ข้อสอบจะถาม** ไม่ใช่ทวนชื่อรูป
   คำบรรยายที่ดีคือประโยคที่ทำให้ผู้เรียนกลับไปมองรูปอีกครั้งแล้วเห็นสิ่งที่พลาดไป
3. **`.figsrc` ต้องอ้างที่มา** — หน้าในชีท/สไลด์ หรือสัญญาอนุญาตถ้าโหลดมา

`fig/` ต้องอยู่ **ใน** `lessons/` (`lessons/fig/…`) ไม่ใช่ข้างนอก
Safari ไม่ยอมโหลดไฟล์ที่ `file://` อ้างขึ้นไปหาโฟลเดอร์แม่ — `src="../fig/x.png"`
จะขึ้นรูปแตกบนเครื่องที่ใช้อ่านจริง ทั้งที่บน Chrome ตอนสร้างดูปกติดี
`preflight.py` บล็อกให้

## รูปที่ผู้เรียนต้องตอบก่อนถึงจะเฉลย

ใส่รูปไว้ใน `.quiz` ได้ — โจทย์ "อวัยวะที่ชี้ด้วยลูกศรคืออะไร" คือข้อสอบชีววิทยา
ที่เจอบ่อยที่สุด และเป็นแบบเดียวที่ฝึกจากตัวหนังสือไม่ได้

```html
<div class="quiz" data-answer="B" data-tag="ทางเดินอาหาร">
  <div class="qtext">ลูกศร <b>X</b> ในรูปชี้ที่อวัยวะใด</div>
  <figure class="fig"><img src="fig/gut-quiz.png" alt="ทางเดินอาหารมีลูกศร X ชี้"></figure>
  <div class="opts">…</div>
  <div class="fb" hidden data-ok="…" data-no="…"></div>
</div>
```

## ตรวจก่อนส่ง

```bash
python3 $S/scripts/figure.py check lessons/fig
```

บอกขนาดจริงและน้ำหนักไฟล์ทุกรูป · เตือนรูปที่เล็กกว่า 520 px (ป้ายในรูปจะเละ
เมื่อย่อลงคอลัมน์ ให้ครอปใหม่ที่ `--dpi` สูงขึ้น) และรูปที่หนักเกิน 1.2 MB

จบงานแล้ว `preflight.py` จะบอกอีกทีว่าหน้าไหนมีรูปกี่รูป และหน้าไหนขาดโควตา
แต่ **ไม่มีสคริปต์ไหนบอกได้ว่ารูปนั้นถูกไหม** — ทุกรูปที่ครอปหรือโหลดมาต้องเปิดดูเอง
อย่างน้อยหนึ่งครั้งก่อนส่งมอบ ครอปเบี้ยวหนึ่งพิกเซลไม่เป็นไร ครอปผิดรูปคือสอนผิด
