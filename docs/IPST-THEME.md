# ธีม สสวท — งาน PDF ที่หน้าตาตรงกับหนังสือเรียน

ชีทของครูส่วนใหญ่ถ่ายจากหนังสือเรียน สสวท. **ธีม สสวท** คือชุดกราฟิกที่ทำให้
เฉลยและแบบฝึกหัดที่เราสร้าง วางต่อกับชีทต้นฉบับแล้วดูเป็นเล่มเดียวกัน

ทำไมต้องเหมือน: คืนก่อนสอบ คนอ่านสลับไปมาระหว่างชีทกับเฉลยสิบกว่ารอบ
หน้าตาที่กระโดดทุกครั้งที่สลับ คือภาระที่ไม่จำเป็นในชั่วโมงที่ไม่มีให้เสีย —
และป้ายหัวเรื่อง/เลขข้อที่อยู่ตำแหน่งเดิม ทำให้ไล่หา "ข้อ 13 ข้อย่อย 4" เจอโดยไม่ต้องอ่าน

## สีของธีม — ห้ามเดา ให้ดูดจากไฟล์จริง

ทุกค่าด้านล่างดูดจากไฟล์สแกนของหนังสือ ไม่ได้กะจากตา

| ชื่อ | ค่า | ใช้ที่ |
|---|---|---|
| `skrpurple` | `#813294` | แถบหัวกระดาษ · แถบหัวเรื่อง · วงกลมเลขข้อ |
| `skrred` | `#BF3855` | กล่องเลขหน้า · คำว่า "กับดัก" |
| `skrtag` | `#F2DADA` | พื้นป้าย "บทที่ N \| ชื่อบท" |
| `skrlav` | `#E6D8EC` | พื้นกล่องเนื้อหา |
| `skrblue` | `#305BAD` | ฟุตเตอร์ สสวท. · คำว่า "สังเกต" |

หนังสือคนละเล่มอาจใช้คนละโทน (คณิตม่วง ชีววิทยาเขียว ฯลฯ) **ให้ดูดสีใหม่ทุกครั้ง**
อย่าใช้ค่าข้างบนกับเล่มที่ยังไม่ได้ตรวจ:

```python
import pymupdf, collections
pix = pymupdf.open("ชีท.pdf")[0].get_pixmap(dpi=150)
c = collections.Counter()
for y in range(int(pix.height*0.075), int(pix.height*0.095), 2):      # ช่วงแถบหัว
    for x in range(int(pix.width*0.20), int(pix.width*0.80), 2):
        c[pix.pixel(x, y)] += 1
print(c.most_common(3))
```

## มาโครที่ธีมให้

**ชั้นฐาน (`ipst-theme.tex`)**

| มาโคร | ได้อะไร |
|---|---|
| `\ipstchaptag` · `\ipstband` | ป้ายบทและข้อความบนแถบหัว — **สองตัวนี้คือที่เดียวที่ต้อง `\renewcommand`** |
| `sheetbox` (env) | กล่องพื้นม่วงอ่อน ต่อหน้าได้ และจบตรงที่เนื้อหาจบ |
| `\SectionBar{...}` | แถบม่วงหัวเรื่อง แบบ "แบบฝึกหัดท้ายบท" ในเล่ม |
| `\Q{เลขข้อ}{โจทย์}` | วงกลมเลขข้อม่วง + ตัวโจทย์ 18pt |
| `soln` (env) | บล็อกวิธีทำ 16pt เยื้องตรงกับตัวโจทย์ |
| `\sub{n}` | หัวข้อย่อย `n)` |
| `\Ans{...}` | กล่องคำตอบ (ตัดบรรทัดได้) |
| `\Note{...}` · `\Trap{...}` | บล็อก "สังเกต" (น้ำเงิน) และ "กับดัก" (แดง) |
| `\bmt{a & b \\ c & d}` | เมทริกซ์ จัดตัวเลขชิดขวาแบบในเล่ม |
| `\ok` | เครื่องหมายถูก (ต้องใช้ตัวนี้ `\checkmark` เปล่า ๆ พังใน text mode) |

**ชั้นแบบฝึกหัด (`ipst-worksheet.tex`)**

| มาโคร | ได้อะไร |
|---|---|
| `\WS{เลขข้อ}{โจทย์}` | หนึ่งหน้า: กล่องโจทย์ + กรอบพื้นที่ทำที่ยืดกินหน้าที่เหลือทั้งหมด |
| `\WS[3)]{7}{โจทย์}` | เหมือนกัน แต่มีป้าย "ข้อ 7 ข้อย่อย 3)" |
| `\refstrip{...}` | แถบ "โจทย์กำหนดให้" ย่อ 12.5pt สำหรับซ้ำหัวทุกหน้าย่อย |

### แบ่งหน้ายังไงเมื่อข้อหนึ่งมีข้อย่อยสิบข้อ

"หนึ่งข้อหนึ่งหน้า" ตรงตัวไม่ได้แปลว่าใช้ได้ — ข้อที่มีสิบข้อย่อยยัดหน้าเดียว
ก็ไม่มีที่เขียนอยู่ดี ซึ่งขัดกับเหตุผลที่ทำแยกหน้าตั้งแต่แรก เกณฑ์ที่ใช้:

- ข้อย่อยที่ต้อง **คูณเมทริกซ์เต็ม ๆ หรือแก้ระบบสามตัวแปร** → หน้าของตัวเอง
- ข้อย่อยที่เป็น **det/ผกผัน 2×2 หรือแทนค่าสั้น ๆ** → สองข้อต่อหน้า

**ข้อที่นิยามเมทริกซ์ไว้ตอนต้นแล้วใช้ยาวสิบข้อย่อย ให้ `\refstrip` ซ้ำหัวทุกหน้า**
กินที่ราว 15% แต่ไม่ต้องพลิกกลับไปหน้าแรกทุกครั้ง — คุ้มกว่ามาก

เป้าพื้นที่เขียน **ไม่ต่ำกว่า ~290pt** (≈ 10 บรรทัด) ต่อหน้า วัดได้ด้วย
`page.get_drawings()` แล้วหาความสูงของกรอบ

`preflight.py` เป็นตัวตรวจบทเรียน HTML ใช้กับ PDF ไม่ได้ ให้ตรวจสองอย่างนี้แทน:

```python
# 1) สมการล้นขอบกล่อง — อาการที่พบบ่อยที่สุดของธีมนี้
import pymupdf
d = pymupdf.open("งาน.pdf"); RIGHT = 539.0          # ขอบขวาของกล่องเนื้อหา
for i, p in enumerate(d, 1):
    for b in p.get_text("dict")["blocks"]:
        if b["type"]: continue
        for l in b["lines"]:
            if max(s["bbox"][2] for s in l["spans"]) > RIGHT + 1 \
               and 100 < l["bbox"][1] and l["bbox"][3] < 760:
                print("ล้น", i, "".join(s["text"] for s in l["spans"])[:60])

# 2) ฟอนต์ฝังครบ — ต้องเห็น THSarabunNew ทั้ง Regular และ Bold
print(sorted({x[3].split("+")[-1] for p in d for x in p.get_fonts()}))
```

เจอล้น **อย่าย่อฟอนต์หรือขยายขอบ** ให้หักบรรทัดสมการนั้นด้วย `aligned` หรือแยกเป็นสองบรรทัด
ขอบกระดาษคือส่วนหนึ่งของความเหมือน ไม่ใช่ที่ว่างให้ยืม

## ข้อควรระวังที่เสียเวลาไปแล้ว

- `\documentclass[16pt]` ไม่มีจริงใน `article` — ใช้ `[12pt]` แล้ว `\AtBeginDocument{\solnsize}`
- `\checkmark` ใน text mode ได้กล่องว่าง ให้ใช้ `\ok` ที่ธีมนิยามไว้
- `\dimen0` ใส่ในพิกัด TikZ ไม่ได้ ต้อง `\newlength` แล้วส่ง `\the\ความยาว`
- `&` ของ `\bmt` ชนกับ `aligned` ที่ครอบอยู่ — อย่าใส่ `\bmt` ในบรรทัดที่มี `&` ของ `aligned`
- บรรทัดว่างกลาง `\[ ... \]` ทำให้ display math พัง (ระวังตอนแก้ไฟล์ด้วยสคริปต์)
