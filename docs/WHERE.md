# WHERE — ชีววิทยา: ทุกกระบวนการต้องบอกว่าเกิดที่ไหน

ข้อสอบชีวะในโรงเรียนถาม **"เกิดที่ใด / หลั่งจากเซลล์ใด / ออกฤทธิ์ที่ใด"**
บ่อยกว่าถามว่ากลไกทำงานยังไง เพราะตำแหน่งเป็นสิ่งที่ตรวจให้คะแนนได้ตรง ๆ
และเป็นสิ่งที่ผู้เรียนที่อ่านผ่าน ๆ ตอบไม่ได้

ปัญหาคือตำแหน่งมักกระจายอยู่ในย่อหน้า — "เอนไซม์นี้สร้างจากตับอ่อน" อยู่ประโยคหนึ่ง
"ทำงานได้ดีที่ pH 8" อยู่อีกย่อหน้า ผู้เรียนอ่านจบแล้วยังต่อไม่ติดว่ามันทำงานที่ลำไส้เล็ก
**บล็อก `.where` บังคับให้ตอบเป็นช่อง ๆ ไม่ใช่หวังว่าคำตอบจะอยู่ในเนื้อความ**

## มาร์กอัป

```html
<div class="where"><span class="where-head">เกิดที่ไหน</span>
  <dl>
    <dt>อวัยวะ</dt>       <dd>กระเพาะอาหาร (stomach)</dd>
    <dt>ส่วน / เซลล์</dt> <dd>gastric gland ที่ผนัง → <b>chief cell</b> และ <b>parietal cell</b></dd>
    <dt>สร้างที่</dt>      <dd>chief cell สร้าง pepsinogen (ยังไม่ทำงาน)</dd>
    <dt>ออกฤทธิ์ที่</dt>   <dd><em>ลูเมนของกระเพาะ ไม่ใช่ในเซลล์</em> — HCl จาก parietal cell
                              เปลี่ยนเป็น pepsin ตรงนั้น</dd>
  </dl>
</div>
```

วางไว้ **ใต้หัวข้อ `<h2>` ของกระบวนการนั้นทันที ก่อนคำอธิบาย** —
ผู้เรียนต้องรู้ว่ากำลังยืนอยู่ตรงไหนของร่างกายก่อนจะอ่านว่าเกิดอะไรขึ้น

`<em>` ในช่อง `<dd>` ขึ้นเป็นสีชาด ใช้กับ **จุดที่ข้อสอบดัก** ช่องละไม่เกินหนึ่งที่

## สี่ช่อง และเหตุผลที่ต้องมีสี่

| ช่อง | ตอบว่าอะไร | ทำไมต้องมี |
|---|---|---|
| `อวัยวะ` | ระดับที่มองเห็นด้วยตาเปล่า | คำตอบที่ข้อสอบให้คะแนนบ่อยที่สุด |
| `ส่วน / เซลล์` | เนื้อเยื่อ ต่อม เซลล์ หรือออร์แกเนลล์ | แยกคนที่ท่องชื่ออวัยวะ ออกจากคนที่เข้าใจ |
| `สร้างที่` | ที่ที่สารถูกผลิต/หลั่ง | — |
| `ออกฤทธิ์ที่` | ที่ที่มันทำงานจริง | **คู่นี้คือกับดัก** |

**`สร้างที่` กับ `ออกฤทธิ์ที่` คือหัวใจของบล็อกนี้** ถ้าสองช่องนี้เป็นคนละที่
นั่นคือข้อสอบทั้งข้อ — ตับอ่อนสร้างเอนไซม์แต่ออกฤทธิ์ที่ลำไส้เล็ก · ตับสร้างน้ำดี
แต่เก็บที่ถุงน้ำดีและออกฤทธิ์ที่ดูโอดีนัม · chief cell สร้าง pepsinogen
แต่มันกลายเป็น pepsin ในลูเมน ไม่ใช่ในเซลล์

**ถ้าสองช่องนี้เป็นที่เดียวกัน ให้ยุบเหลือช่องเดียวว่า `เกิดที่`** อย่าเขียนซ้ำสองบรรทัด
เพื่อให้ครบฟอร์ม — ฟอร์มที่กรอกเพื่อให้ครบคือฟอร์มที่ผู้เรียนเรียนรู้ที่จะข้าม

ช่องอื่นเพิ่มได้เมื่อเรื่องนั้นต้องใช้: `ออร์แกเนลล์` (หายใจระดับเซลล์ · สังเคราะห์แสง) ·
`ทิศทาง` (ลำเลียงในพืช: xylem ขึ้น phloem ลง) · `สภาวะ` (pH, แสง, ฮอร์โมนที่กระตุ้น)

## ระดับความละเอียดตามเรื่อง

ไล่ให้ลึกที่สุดเท่าที่ชีทไปถึง **ห้ามเดาลึกกว่าชีท** (กฎการอ้างอิงของชีวะ — [VERIFY.md](VERIFY.md))

| เรื่อง | ต้องไล่ถึงระดับ |
|---|---|
| ย่อยอาหาร | อวัยวะ → ต่อม/เซลล์ที่หลั่ง → **ลูเมนที่ออกฤทธิ์** |
| หายใจระดับเซลล์ | เซลล์ → **ออร์แกเนลล์ → ส่วนย่อยในออร์แกเนลล์** (ไซโทซอล · เมทริกซ์ · เยื่อชั้นใน) |
| สังเคราะห์แสง | ใบ → เซลล์มีโซฟิลล์ → คลอโรพลาสต์ → **กรานา vs สโตรมา** |
| ลำเลียงในพืช | อวัยวะ → เนื้อเยื่อ (xylem/phloem) → **ทิศทาง** |
| ฮอร์โมนพืช | สร้างที่ (ปลายยอด/ราก/ผล) → **เคลื่อนไปออกฤทธิ์ที่ไหน** |
| ฮอร์โมนสัตว์ | ต่อมที่สร้าง → เลือด → **อวัยวะเป้าหมาย (target organ)** |
| ขับถ่าย/หมุนเวียน | อวัยวะ → หน่วยย่อย (หน่วยไต) → **ส่วนของหน่วยย่อยที่เกิดจริง** |

## ผูกกับรูปเสมอ

`.where` บอกชื่อตำแหน่ง **รูปบอกว่าตำแหน่งนั้นอยู่ตรงไหน** สองอย่างนี้ทำงานคู่กัน:
ชื่อที่ไม่มีรูปคือคำที่ต้องท่อง รูปที่ไม่มีชื่อคือภาพที่สวยแล้วลืม

ให้ `figcaption` ของรูปในหัวข้อนั้น **ชี้ไปที่ช่องเดียวกับที่ `.where` เน้น**
ใช้คำเดียวกันเป๊ะ — ถ้า `.where` เขียน "ดูโอดีนัม" คำบรรยายห้ามเขียน "ลำไส้เล็กส่วนต้น"
เพราะผู้เรียนที่กำลังเทียบสองอย่างจะไม่รู้ว่ามันคือที่เดียวกัน ([FIGURES.md](FIGURES.md))

## ต้องขึ้นในบล็อก "คัดลงสมุด" ด้วย

บล็อก `.copy` คือสิ่งเดียวที่ตามผู้เรียนเข้าห้องสอบ (กฎ 5) ตำแหน่งที่อยู่แต่ใน `.where`
กลางหน้า จะไม่ได้ไปด้วย **ทุกบทชีวะต้องมีอย่างน้อยหนึ่งบรรทัดใน `.copy` ที่เป็นตำแหน่ง**
และให้เป็นบรรทัดที่ `สร้างที่` ≠ `ออกฤทธิ์ที่`:

```html
<div class="copy"><span class="copy-head">คัดลงสมุด</span>
<ul>
  <li>ตับอ่อนสร้างเอนไซม์ → ออกฤทธิ์ที่ <b>ดูโอดีนัม</b> ไม่ใช่กระเพาะ</li>
  …
</ul></div>
```

## กลางประโยคใช้ `.at`

```html
<p>เอนไซม์ทริปซินทำงานที่ <span class="at">ลำไส้เล็ก</span> ที่ pH ประมาณ 8</p>
```

ทำให้คำเรียกตำแหน่งในเนื้อความกับใน `.where` เป็นคำเดียวกัน และตาไล่หาเจอตอนอ่านทวน
ใช้กับตำแหน่งเท่านั้น ไม่ใช่ใช้เน้นทุกคำที่สำคัญ

## ควิซที่ถามตำแหน่ง

ทุกบทชีวะต้องมี **อย่างน้อยหนึ่งข้อที่ถามว่าเกิดที่ไหน** เพราะข้อสอบจะถาม
และเพราะเป็นข้อที่ผู้เรียนคิดว่าตอบได้จนกระทั่งถูกถาม

```html
<div class="quiz" data-answer="B" data-tag="ตำแหน่ง-ย่อยโปรตีน">
  <div class="qtext">pepsinogen ถูกเปลี่ยนเป็น pepsin ที่ใด</div>
  <div class="opts">
    <button class="opt" data-k="A">ภายใน chief cell ก่อนถูกหลั่งออกมา</button>
    <button class="opt" data-k="B">ในลูเมนของกระเพาะ หลังถูกหลั่งออกมาแล้ว</button>
  </div>
  <div class="fb" hidden
       data-ok="ถ้าเปลี่ยนตั้งแต่ในเซลล์ เซลล์จะย่อยตัวเอง — นั่นคือเหตุผลที่หลั่งเป็นรูปที่ยังไม่ทำงาน"
       data-no="ถามกลับว่า ถ้ามันทำงานตั้งแต่อยู่ในเซลล์ จะเกิดอะไรกับเซลล์นั้น"></div>
</div>
```

ตั้ง `data-tag` ขึ้นต้นด้วย `ตำแหน่ง-` ทุกข้อที่ถามที่อยู่ — แถบคะแนนท้ายหน้าจะรวม
ให้เห็นทันทีว่า "ที่ผิดคือจำตำแหน่งไม่ได้" ไม่ใช่ "ไม่เข้าใจกลไก" ซึ่งอ่านทวนคนละแบบ

## `preflight.py` ตรวจอะไรให้

รันด้วย `--subject bio` แล้วมันจะเตือน (ไม่บล็อก) เมื่อ:
- หน้าบทเรียนไม่มี `.where` เลยสักบล็อก
- `.where` มีช่องน้อยกว่า 2 ช่อง (กรอกไม่ครบ = ตอบไม่ได้จริง)
- ทั้งหน้าไม่มีควิซที่ `data-tag` ขึ้นต้นด้วย `ตำแหน่ง-`

ที่ตรวจไม่ได้และต้องดูเอง: **ตำแหน่งนั้นถูกไหม** ชีวะไม่มีตัวเลขให้ Python ตรวจ
ทุกช่องต้องย้อนกลับไปหาหน้าในชีทได้ ([VERIFY.md](VERIFY.md))
