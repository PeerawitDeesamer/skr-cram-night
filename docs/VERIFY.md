# VERIFY — ตัวเลขทุกตัวต้องผ่าน Python ก่อน

เฉลยที่ผิดแต่เขียนอย่างมั่นใจ แย่กว่าไม่มีเฉลย เพราะมันสอนวิธีที่จะถูกทำซ้ำ
ในห้องสอบ ตอนที่ไม่มีเวลาสงสัย

## เคมี / ฟิสิกส์ / คณิต

เขียน `verify.py` ใน workspace ก่อนเขียน HTML บรรทัดแรก:

```python
import sys; sys.path.insert(0, "/Users/<you>/.claude/skills/skr/scripts")
from verify_lib import V, ice, kp_from_kc, solve_for, sig

v = V(subject="chem", chapter="บทที่ 9 สมดุล")

r = ice(K=0.0125, init={"N2O4": 0.100}, rxn="N2O4 -> 2 NO2")
v.check("ตย. 9.17 [NO2] สมดุล", sig(r["NO2"], 3), expect=0.0324,
        tol=0.02, source="ชีทหน้า 12")

v.check("ตย. 9.21 Kp", sig(kp_from_kc(0.0125, dn=1, T=298), 3),
        expect=None, source="ชีทไม่ได้ให้เฉลยไว้")   # → COMPUTED ไม่ใช่ PASS

v.save()   # เขียน verify_out.json, exit 1 ถ้ามีข้อไหนไม่ตรงชีท
```

### สถานะสามแบบ

| สถานะ | หมายความว่า |
|---|---|
| `PASS` | คำนวณแล้ว **และ** ตรงกับเฉลยในชีท |
| `COMPUTED` | คำนวณแล้ว แต่ชีทไม่มีเฉลยให้เทียบ — เขียนลงบทเรียนได้ แต่รู้ตัวว่าไม่มีใครยืนยัน |
| `FAIL` | ไม่ตรงชีท — **ห้ามเขียนลงไฟล์** หยุดแล้วหาว่าใครผิด |

`FAIL` ไม่ได้แปลว่าเราผิดเสมอไป ชีทพิมพ์ผิดก็มี (`NOTES.md` ของเคมีจดไว้แล้วสองจุด:
ตย. 9.20 หน้า 13 และแบบฝึกหัด 9.3 ข้อ 14) ถ้าเชื่อว่าชีทผิด **ให้บอกผู้ใช้ตรง ๆ
พร้อมวิธีคิดทั้งสองทาง** อย่าเงียบแล้วเลือกข้างเอง

### เครื่องมือใน verify_lib

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `ice(K, init, rxn, solid=())` | แก้ตาราง ICE ทั้งตาราง คืนความเข้มข้นทุกตัว + x |
| `solve_for(eq, "x", lo=, hi=)` | แก้สมการเดียว คืน "รากที่เป็นไปได้ทางกายภาพ" ตัวเดียว |
| `kp_from_kc` / `kc_from_kp` | แปลงด้วย Δn (นับเฉพาะแก๊ส ผลิตภัณฑ์ลบสารตั้งต้น) |
| `percent_dissoc` | % การสลายตัว |
| `sig(x, 3)` | ปัดเลขนัยสำคัญให้ตรงกับที่ชีทเขียนเฉลย |

`solve_for` จะ **โยน error เมื่อมีรากที่ใช้ได้มากกว่าหนึ่ง** ตั้งใจให้เป็นแบบนั้น —
ICE ที่ได้สองรากแปลว่าตั้งสมการผิด การหยิบรากแรกมาเงียบ ๆ คือวิธีสอนวิธีผิด
`solid=("CaCO3",)` สำหรับของแข็ง/ของเหลวบริสุทธิ์ที่ต้องตัดออกจาก K — กับดักที่ชีทวางซ้ำ ๆ
