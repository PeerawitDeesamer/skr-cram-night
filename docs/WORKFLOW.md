## จุดตัดสินใจตามเวลาที่เหลือ

ถามข้อ 3 ("คืนนี้มีกี่ชั่วโมง") แล้วเลือก:

| เวลา | ทำแค่ไหน |
|---|---|
| < 2 ชม. | 2–3 บท high-yield + บล็อก "คัดลงสมุด" + reveal เฉพาะโจทย์ที่ครูเน้น · รูปเฉพาะที่ `figure.py pull` ดึงได้ตรง ๆ (เร็วที่สุด) |
| 2–4 ชม. | ครบทุกบทของช่วงหน้าที่สอบ + reveal ทุกแบบฝึกหัดในช่วงนั้น · รูปครบโควตา ครอปจากสไลด์ |
| > 4 ชม. หรือมีหลายวัน | เพิ่มหน้า reference (สรุป/อภิธานศัพท์) + ควิซคละบท + วาด SVG เองสำหรับเรื่องที่ชีทไม่มีรูป |

**เวลาไม่พอให้ตัดบท ไม่ใช่ตัดรูป** บทที่มีรูปครบสามบท ใช้ได้จริงกว่าห้าบท
ที่เป็นตัวหนังสือล้วน — อย่างหลังคือของที่ถูกเลื่อนผ่านทั้งชุด (กฎ 9)

**กฎการหยุด:** หยุดเมื่อไรก็ได้ แต่บทที่ค้างต้องไม่ถูกส่งมอบครึ่ง ๆ กลาง ๆ
เขียนทีละบทให้จบเป็นบท ๆ ไม่ใช่เขียนทุกบทพร้อมกันแบบครึ่งเดียว

## การมอบงานให้ Sonnet

subagent ไม่เห็นบทสนทนานี้ ส่งไปให้ครบในคำสั่งเดียว:
- โครงบททั้งหมด **ตามลำดับที่จัดไว้แล้ว** (เลขบท ชื่อ หน้าในชีทที่อ้าง — รวมทุกช่วงหน้า
  ถ้าบทนั้นรวมหลายช่วง — ตย./แบบฝึกหัดที่ครอบคลุม) subagent ต้องตั้งชื่อไฟล์ `0001-…`
  ตามลำดับนี้ ไม่ใช่ตามเลขหน้าในชีท
- เนื้อหาที่ Opus ตัดสินใจแล้ว: กับดัก เฉลย ใบ้ ตัวเลขที่ verify แล้ว
- **รายการรูปต่อบท**: ไฟล์สไลด์ + หน้า + `--index` หรือ `--box` + ชื่อไฟล์ปลายทาง
  + `alt` + คำบรรยาย บทไหนต้องวาด SVG เอง ให้บอกว่าวาดอะไรและมีป้ายอะไรบ้าง
- path ของ workspace, `docs/LESSON-FORMAT.md` และ `docs/FIGURES.md`
- คำสั่งให้รัน build + `figure.py check` + preflight เอง แล้วรายงานผลกลับ
