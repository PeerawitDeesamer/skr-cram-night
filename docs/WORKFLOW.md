ที่เหลือของคืนเป็นของผู้เรียน ไม่ใช่ของเครื่อง

## ลำดับ

| ขั้น | ใคร | ทำอะไร | ห้ามข้ามเพราะ |
|---|---|---|---|
| 0 | Opus | ถาม 3 คำถาม + `results.py weak` + พูดสเปกกลับ | เดาผิดตอนตี 1 = ทำใหม่ทั้งชุด |
| 1 | Opus | `sheet.py probe` แล้ว `text` หรือ `render` | เดาว่าอ่านได้แล้วเจอสแกน = เสียเวลาสองรอบ |
| 2 | Opus | แบ่งบท เรียง high-yield ระบุกับดัก | หยุดกลางทางแล้วต้องยังใช้ได้ |
| 3 | Opus | เขียน `verify.py` + เฉลยโจทย์ยาก + ใบ้ | ตัวเลขผิด = สอนวิธีผิด |
| 4 | Sonnet | เขียน HTML ทุกหน้าตามโครง | งานกลไก ไม่ต้องใช้การตัดสินใจ |
| 5 | Sonnet | `verify.py` → `build.py` → `preflight.py` | ต้องผ่านก่อนถึงจะส่งได้ |
| 6 | Opus | บอกว่าหน้าไหนต้องดูด้วยตา แล้วส่งมอบ | ไม่มีสคริปต์ไหนตรวจได้ว่ารูปถูกไหม |

## จุดตัดสินใจตามเวลาที่เหลือ

ถามข้อ 3 ("คืนนี้มีกี่ชั่วโมง") แล้วเลือก:

| เวลา | ทำแค่ไหน |
|---|---|
| < 2 ชม. | 2–3 บท high-yield + บล็อก "คัดลงสมุด" + reveal เฉพาะโจทย์ที่ครูเน้น |
| 2–4 ชม. | ครบทุกบทของช่วงหน้าที่สอบ + reveal ทุกแบบฝึกหัดในช่วงนั้น |
| > 4 ชม. หรือมีหลายวัน | เพิ่มหน้า reference (สรุป/อภิธานศัพท์) + ควิซคละบท |

**กฎการหยุด:** หยุดเมื่อไรก็ได้ แต่บทที่ค้างต้องไม่ถูกส่งมอบครึ่ง ๆ กลาง ๆ
เขียนทีละบทให้จบเป็นบท ๆ ไม่ใช่เขียนทุกบทพร้อมกันแบบครึ่งเดียว

## การมอบงานให้ Sonnet

subagent ไม่เห็นบทสนทนานี้ ส่งไปให้ครบในคำสั่งเดียว:
- โครงบททั้งหมด (เลขบท ชื่อ หน้าในชีทที่อ้าง ตย./แบบฝึกหัดที่ครอบคลุม)
- เนื้อหาที่ Opus ตัดสินใจแล้ว: กับดัก เฉลย ใบ้ ตัวเลขที่ verify แล้ว
- path ของ workspace และ `docs/LESSON-FORMAT.md`
- คำสั่งให้รัน build + preflight เอง แล้วรายงานผลกลับ
